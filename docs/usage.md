# 使用说明（当前可试用版）

## 五页导航

- `首页`：开始/停止、取消、阶段状态、最近结果、今日统计
- `记忆`：历史时间线与筛选管理
- `技能`：开关式技能中心
- `模型`：ASR + 文本处理配置与测试
- `设置`：热键、权限、场景策略、关于

## 默认快捷键

- 主快捷键（开始/停止）：`Control + Option + Space`
- 取消当前会话：`Escape`

说明：聆听中再次按主快捷键，会直接停止录音并进入转写流程。

## 首次配置（3 分钟内可完成）

1. 打开“模型”页。
2. 填写两张卡片：
   - 语音识别（ASR）
   - 文本处理
3. 分别填写：
   - API 地址
   - 模型名
   - API 密钥（保存到钥匙串）
4. 点“测试 ASR”和“测试文本模型”，确认都成功。
5. 打开“设置”页，在“权限中心”请求：
   - 麦克风
   - 辅助功能
6. 回到“首页”，即可开始语音输入。

## 语音输入路径

1. 在任意输入框聚焦光标，打开“首页”。
2. 按主快捷键开始录音。
3. 说话。
4. 再按一次主快捷键停止。
5. 等待转写与写回完成。

## 选区改写路径

1. 在目标应用先选中一段文本。
2. 按主快捷键开始录音。
3. 说出改写意图（如“翻译成日语”“更正式一点”）。
4. 再按主快捷键停止。
5. 系统会用改写结果覆盖选区原文。

## 常见问题定位

- 测试失败且 HTTP 401：
  - 密钥错误或未生效，重新保存密钥再试。
- 测试失败且 HTTP 404：
  - Base URL 或模型名可能不对。
- 测试失败且 HTTP 429：
  - 额度不足或触发限流。
- 无法开始录音：
  - 麦克风权限未允许。
- 选区改写无法进入：
  - 辅助功能权限未允许，或当前没有有效选区。
- 首页看不到最近统计：
  - 需要先完成至少一条本地历史记录。
- 记忆页没有内容：
  - 检查是否被筛选到“失败/选区改写”等子集合。
