# PulseType 1.1

PulseType 是一个给 macOS 用的 AI 语音输入助手。它不是系统输入法，而是独立 app，核心思路是“键盘优先 + 语音增强 + 场景化写作”。

## 1.1 亮点

- `单击主键`：普通听写，语音转文字后直接写回当前 app
- `长按主键`：进入 `魔术先生`，按住说命令，松开立刻执行
- `双击脑暴键`：进入 `一口气全念对`，把一段连续表达整理成可继续使用的结论
- `记忆` 页面支持按模式筛选，能分别查看普通听写、魔术先生、一口气全念对、失败记录
- `HUD` 和状态提示更干净，重点只显示动作语义，不再塞实现细节

## 现在能做什么

- 全局热键：主键、取消键、一口气全念对键
- 本地录音 + 云端 `ASR`
- 听写文本自动写回前台 app
- `魔术先生`
  - 文字处理：翻译、润色、精简、结构化
  - 一键建日程
  - 写入备忘录
  - 邮件草稿
- `一口气全念对`：把连续口述整理成更清晰的输出
- 双模型配置：`ASR` + `Text`
- 默认模型组合：`Qwen3-ASR-Flash` + `deepseek-chat`
- 可切到本地 `ASR`：`SenseVoice Small`
- 模型连接一键测试
- 本地词典：每行一个词条，保存后立刻生效
- 个性提示词：按 app 定制输出风格
- 本地记录：筛选、复制、删除、清空
- 权限中心：麦克风、辅助功能、日历等状态检查
- 菜单栏 + 主窗口 + `HUD` 状态提示

## 页面说明

- `首页`：会话状态、近期内容、累计指标
- `记忆`：本地记录列表与筛选管理
- `词典`：`ASR` 词条配置
- `Skill`：口语过滤、个性提示词、系统提示词
- `模型`：`ASR/Text` 参数、密钥与连通测试
- `魔术先生`：长按触发、能力开关、权限引导
- `一口气全念对`：连续表达整理入口
- `设置`：热键、权限、运行诊断、关于

## 快速开始

1. 生成工程

```bash
xcodegen generate
```

2. 覆盖安装到 `/Applications`

```bash
./scripts/install-local-app.sh
```

3. 打开 `/Applications/PulseType.app`

4. 在 `模型` 页填好 `ASR` 和 `Text` 配置，并执行连通测试

5. 在 `设置` 页确认麦克风与辅助功能权限

6. 回到主界面开始体验：
   - 单击主键：普通听写
   - 长按主键：魔术先生
   - 双击脑暴键：一口气全念对

## 已知限制

- 直接写入路径在不同 app 上仍有差异
- `魔术先生` 的部分能力依赖系统权限或系统 app 可用性
- 本地 `SenseVoice` 依赖本机 runtime 与模型目录
- 目前还没有签名/公证后的发行安装包

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild \
  -project PulseType.xcodeproj \
  -scheme PulseType \
  -configuration Debug \
  test
```
