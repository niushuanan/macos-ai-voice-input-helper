# 使用说明（当前可试用版）

## 五页导航

- `首页`：开始/停止、取消、阶段状态、最近结果、今日统计
- `记忆`：历史时间线与筛选管理
- `技能`：口语过滤、个性提示词、按应用风格总开关与策略编辑
- `模型`：ASR + 文本处理配置与测试
- `设置`：热键、权限、关于

## 默认快捷键

- 主快捷键（开始/停止）：`Control + Option + Space`
- 取消当前会话：`Escape`

说明：聆听中再次按主快捷键，会直接停止录音并进入转写流程。

## 首次配置（3 分钟内可完成）

1. 打开“模型”页。
2. 检查两张卡片默认值：
   - 语音识别（ASR）
   - 文本处理
3. 云端默认建议：
   - ASR：`https://dashscope.aliyuncs.com` + `qwen3-asr-flash`
   - 文本：`https://api.deepseek.com` + `deepseek-chat`
4. 分别填写：
   - API 地址
   - 模型名
   - API 密钥（保存到钥匙串）
5. 点“测试 ASR”和“测试文本模型”，确认都成功。
6. 打开“设置”页，在“权限中心”请求：
   - 麦克风
   - 辅助功能
7. 如果你希望不同应用自动套用不同文风，到“技能”页配置“按应用风格”。
8. 回到“首页”，即可开始语音输入。

## 语音输入路径

1. 在任意输入框聚焦光标，打开“首页”。
2. 按主快捷键开始录音。
3. 说话。
4. 再按一次主快捷键停止。
5. 如果当前有可编辑输入框，结果会直接写进去，同时也会复制到剪贴板。
6. 如果当前没有可编辑输入框，结果会只复制到剪贴板，并给出明确提示。

## ASR 模型切换（云端/本地）

1. 打开“模型”页的 ASR 卡片。
2. 在 Provider 下拉中切换：
   - `DashScope Qwen ASR`
   - `OpenAI / OpenAI 兼容`
   - `本地 SenseVoice（实验）`
3. 如果选本地 SenseVoice：
   - 检查模型路径是否正确
   - 看“可用性检测”提示
4. 再点“测试 ASR”，确认当前选项可用。

## 选区改写路径

1. 在目标应用先选中一段文本。
2. 按主快捷键开始录音。
3. 说出改写意图（如“翻译成日语”“更正式一点”）。
4. 再按主快捷键停止。
5. 系统会用改写结果覆盖选区原文。

## 常见问题定位

- 测试失败且 HTTP 401：
  - 密钥错误或未生效，重新保存密钥再试。
- 测试失败且 HTTP 404：
  - Base URL 或模型名可能不对。
- 测试失败且 HTTP 429：
  - 额度不足或触发限流。
- 无法开始录音：
  - 麦克风权限未允许。
- 选区改写无法进入：
  - 辅助功能权限未允许，或当前没有有效选区。
- 首页看不到最近统计：
  - 需要先完成至少一条本地历史记录。
- 记忆页没有内容：
  - 检查是否被筛选到“失败/选区改写”等子集合。
